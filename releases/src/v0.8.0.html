A page fails on

HTTP status ≥ 400 an uncaught JavaScript error a failing or 5xx request to the app's own API a console error an "expect" element that is not visible a redirect to login ("notAt") an action that cannot be done + the assistant reads every PNG: blank page, error boundary or broken layout fails even if checks pass

Uses what is there

Playwright from the project first, then a global install. Google Chrome first, then Playwright's Chromium. Asks before installing anything.

Local only

Never production or staging, never a migration outside the local container, never a deploy, never a real email — it proposes the project's safe setting first.

Reports, never fixes

No code edits, nothing committed (.pspt-smoke/ is excluded from git). A failure is offered as a /pspt:ticket.
