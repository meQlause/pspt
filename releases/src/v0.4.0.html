S7 — the finished app matches the mockup

A new last stage of /pspt:spec: fonts, sizes, weights, padding, margins, assets and every interaction, measured against the mockup itself.

The mockup is the baseline — measured in Chromium, never by eye

Four checks, one per way an app drifts from its mockup

① Look

Screenshot of mockup vs app for every file × state × width from the mockup's own breakpoints.

Pixel diff ≤ 0.1% — still catches a 1px padding change.

② Type & spacing

getComputedStyle on both sides: font family, size, weight, line-height, letter-spacing, colour; padding, margin, gap, radius, shadow — incl. hover, focus, active, disabled.

Exact match.

③ Assets

Every image, SVG, icon, font file and favicon the mockup renders, inventoried with its dimensions.

sha256 identical — or an approved derivative.

④ Behaviour

Every handler, toggled class and ?state= in the mockup → a row → an e2e test against the real API.

Reached by its real trigger, never ?state=.
