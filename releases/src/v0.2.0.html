Submodules, auto-commit, and two new skills

The first build creates the backend and frontend repositories; every writing skill now commits its own work.

Repository layout — created by the first /pspt:build

<parent repo>/ docs/ ← the spec, one place, never copied .gitmodules backend/ → <owner>/<slug>-backend gh repo create --private frontend/ → <owner>/<slug>-frontend code only

Requires gh, authenticated (SR-3). Commit inside the submodule first, then the parent so the pointer moves in the same change.
